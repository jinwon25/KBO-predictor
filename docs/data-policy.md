# 데이터 및 공개 정책

2026년 10월 13일 시즌 결산과 연구 계획을 보완했습니다. 주최 측 공개 팀 페이지의 요약 성적을 출처·조회일과 함께 기록하며, 실제 API 응답·경기별 예측·제출 원장·학습 아티팩트는 공개본에 포함하지 않습니다. 대회 종료 자체가 제공 데이터의 재배포 허용을 의미하지 않습니다.

## 검토 근거

2026-10-04에 [공식 정책안](https://www.statiz.co.kr/board/?b_code=10000&b_idx=4294959131&cate=10100&m=main&mode=view)과 참가자가 보관한 제출 안내·대회 안내를 검토했습니다. 2026-10-13에 공식 정책 페이지와 [참여 팀 페이지](https://www.statiz.co.kr/prediction/?m=university_detail&ptt_idx=70)를 다시 조회했습니다. 안내 원문·전체 HTML·참가 서류는 재배포하지 않습니다. 별도 참가 서약·FAQ·종료 후 제출 공지와 추가 합의 전체를 확보한 것은 아닙니다.

| 자료 | 공개본 처리 |
| --- | --- |
| 대회 제공 기록 및 API 응답 | 포함하지 않음 |
| 데이터에서 학습한 가중치·보정값·상태 파일 | 포함하지 않음 |

| 시즌 회고·문헌 기반 후속 연구 설계 | 결과·진단·미실행 계획을 구분해 설명 |
| 인증키·등록 IP·운영 설정 | 포함하지 않음 |

| 실제 운영 UI의 정적 표시 기록 | 독립 합성 입력 사용. 원본 JavaScript·실행 제어·외부 연결 제외 |
| 독립 작성 데모와 가상 입력 | 공개 |
| 설계 설명 및 검증 예제 | 공개 |

대회 데이터의 목적 외 사용·재배포와 인증키 유출을 금지하는 조건을 고려해 공개본을 별도로 작성했습니다. 참가 결과의 공개 인용과 제공 데이터·학습 산출물의 재배포는 서로 다른 범위입니다. 이는 모든 공동 작업물의 공개 권한을 추정한다는 뜻이 아닙니다. 향후 실제 모델이나 자료를 추가하려면 팀의 권한과 주최 측 조건을 다시 확인해야 합니다.

사용자 요청 범위에서 운영 화면 구성을 기록하고, 실제 자료에서 추출하지 않은 가상 입력으로 표시했습니다. [기록 방식](dashboard-showcase.md)에 원본 서버 데이터 화면의 캡처와 다른 점을 명시했습니다. 정적 HTML은 표시된 화면을 읽는 자료이며 운영 코드를 재배포하거나 대회 시스템을 실행하는 예제가 아닙니다.

## 채점 예제의 가정

공식 정책은 홈팀 기준 확률, 50%의 실패 처리, 미제출의 실패 처리, 경기 시작 15분 전 마감, 취소·무승부·더블헤더 2차전 제외를 규정합니다. 참가자 안내는 소수 둘째 자리 제출과 `50.001 → 50.00` 예시를 추가로 설명합니다.

데모는 소수 셋째 자리의 정확한 중간값에 `ROUND_HALF_UP`을 사용하고, 마감 정각에 수신된 제출을 허용합니다. 두 경계의 서버 구현은 확인되지 않았습니다. 원본 확률이 범위를 벗어나면 반올림 전에 오류로 처리합니다. 제출 후 주최 측 테이블과 대조하는 운영 절차를 대신하지 않습니다.

공식 정책의 월별 제출률 기준 및 기타 참가·운영 조건 전체를 이 채점 함수 하나로 검사하지 않습니다. 공개본은 규정 준수 인증 도구가 아닙니다.

## 추가 전 확인

공식 정책은 대회 기간 작성한 코드·분석 파일의 별도 보존 및 종료 후 제출을 요구합니다. 공개 예제 저장소와 실제 운영 원본은 용도가 다르므로, 원본의 미커밋 변경이나 모델·분석 기록을 복제본으로 오인해 삭제하지 않습니다.

새 파일을 추가할 때 `python tools/check_publication.py`를 실행합니다. 검사는 허용 확장자, 민감 파일명, 키 형태, 외부 운영 주소 등의 일반적인 실수를 탐지합니다. 자동 검사는 개인정보·저작권·데이터 출처에 대한 사람의 검토를 대체하지 않습니다. 실제 자료를 익명화해 넣는 대신 독립적인 합성 예시를 사용합니다.
