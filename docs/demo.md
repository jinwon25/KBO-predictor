# 합성 데이터 데모

이 문서의 모든 이미지는 **공개 예제 화면이며 실제 운영 웹페이지 캡처가 아닙니다.** 운영 시스템에서 다룬 평가·표시 문제를 설명하기 위해 별도로 작성했습니다. 가상 시즌과 팀을 사용하며, 수치는 모델 성능이나 대회 실적을 나타내지 않습니다.

## 운영본과 다른 점

| 영역 | 실제 운영 시스템 | 공개 예제 |
| --- | --- | --- |
| 메뉴 | 경기 예측·정확도·제출 현황·관리 콘솔 | 경기 예측·통계 분석·운영 안내 |
| 경기 화면 | 미니 카드와 상세 비교 지표를 함께 표시 | 가상 경기 카드로 상태 표시만 설명 |
| 통계 | 모델·기간·팀별 분석 및 정렬 | 합성 월별·요일별·모델별 집계 |
| 관리 | 산출물·모델·실행 및 서버 로그 관리 | 기능 실행 없는 안내문 |
| 실행 | 일정에 따른 모델 실행·제출 관리 | 외부 API 연결과 제출 없음 |

## 채점 예제

- 홈팀 기준 확률을 소수 둘째 자리로 정규화합니다.
- 정규화 후 `50.00%`, 미제출, 마감 후 제출은 실패로 처리합니다.
- 취소·무승부·더블헤더 2차전은 평가에서 제외합니다.
- 평가 분모에는 제출하지 않은 대상 경기까지 포함합니다.

주최 측 서버와 동등함을 검증한 채점기가 아닙니다. 반올림과 마감 정각 처리의 가정은 [공개 정책](data-policy.md)을 참고하세요.

## 선택적인 화면 검증

실행 방법은 [README](../README.md#5-공개-예제-실행과-검증)에 있습니다. Playwright를 설치하면 5개 화면 폭에서 세 화면과 통계 탭을 검사하고 이 문서의 예제 이미지를 생성합니다.

```bash
python -m pip install playwright
python -m playwright install chromium
python tools/check_ui.py
```

운영 서버를 접속하거나 테스트하는 도구가 아닙니다.
