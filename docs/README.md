## 용어

| 용어 | 뜻 |
| --- | --- |
| 공식 페이지 표기 | 주최 측 공개 참가 페이지의 조회 시점 기록. 최종 심사·수상 발표와 구별 |
| 내부 평가 | 보존된 예측과 대응하는 결과를 평가한 값. 전체 참가 성적과 분모가 다를 수 있음 |
| PIT | Point-in-time. 예측 시점 이전에 이용 가능한 자료만으로 입력을 구성하는 조건 |
| 사후 재구성 | 나중에 받은 자료로 과거 입력을 다시 만든 것. 당시 이용 가능성을 따로 검증해야 함 |
| 동결 후보 | 학습·설정을 고정한 뒤 이후 경기에서 확률을 보존하는 비교 모델 |
| 확률 보정 | 예측 확률과 실제 빈도의 일치를 점검·조정하는 과정 |
| Brier·LogLoss | 확률 예측의 품질 지표. 승자 적중률이나 보정만을 단독으로 뜻하지 않음 |
| 표본 수축 | 관측 표본이 적을 때 사전 기준을 함께 반영해 극단적인 비율을 줄이는 방법 |
| 합성 데이터 | 실제 경기·제출 기록에서 만들지 않은 독립 예제. 운영 성능의 증거로 사용하지 않음 |

## 기록 해석

현재 고도화안은 설계 단계입니다. 새 후보를 학습하거나 평가한 성과를 미리 기재하지 않습니다. 공개 데모 실행, 내부 모델 평가, 주최 측 전체 참가 기록과 자료 공개 권한은 각각 확인합니다.
