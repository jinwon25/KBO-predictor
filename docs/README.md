# 시스템 문서 안내

[프로젝트 README](../README.md)는 실제 운영 프로젝트의 목적과 공개본의 범위를 설명합니다. 이 저장소에는 운영 데이터·모델 대신 합성 데이터로 만든 실행 예제가 들어 있습니다.

## 읽는 순서

1. [구조와 공개 데모](architecture.md): 실제 운영 시스템과 공개 예제의 범위를 구분합니다.
2. [합성 데이터 데모](demo.md): 예제 실행 방법과 화면을 확인합니다.
3. [데이터·공개 정책](data-policy.md): 제외한 데이터와 모델, 공개 제한의 근거를 확인합니다.

## 먼저 이해할 용어

| 용어 | 이 프로젝트에서의 뜻 |
|---|---|
| 합성 데이터 | 설명과 실행 확인을 위해 만든 예제 자료입니다. 실제 경기 예측 성능을 입증하지 않습니다. |
| 추론(inference) | 학습된 모델에 입력을 넣어 예측하는 단계입니다. 공개 예제의 계산과 운영 모델 추론을 구분합니다. |
| 운영 파이프라인 | 수집·전처리·예측·결과 저장을 연결한 처리 흐름입니다. |
| 확률 보정(calibration) | 예측 확률과 실제 결과 빈도의 일치 정도를 점검·조정하는 과정입니다. 공개 합성 예제로 운영 성능을 평가하지 않습니다. |

## 해석 기준

공개 데모가 실행되는 것과 실제 운영 모델의 점수·자동화를 재현하는 것은 별개입니다. 실행에 필요한 파일과 제외한 자산은 각 문서의 공개 범위를 따릅니다.
