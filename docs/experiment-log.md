# 실험 기록 양식

후속 연구의 가설·자료 시점·선택 과정·평가 결과를 하나의 기록으로 연결합니다. E0–E5 후보는 설계 단계이며, R0–R7은 아래 표에 실행 범위와 미실행 부분을 구분했습니다.

[문서 목록](README.md) · [연구 고도화 계획](research-plan.md)

## 현재 후보 상태

| ID | 제목 | 상태 | 관측된 새 성능 |
| --- | --- | --- | --- |
| E0 | 입력 정의·가용 시각의 정합성 | 설계 | 없음 |
| E1 | 원시 투수 카운트와 표본 수축 | 설계 | 없음 |
| E2 | 리그 환경 상대 지표와 단순 모델 | 설계 | 없음 |
| E3 | 독립 구간의 낮은 자유도 보정 | 설계 | 없음 |
| E4 | 날짜·블록 단위 불확실성 | 설계 | 없음 |
| E5 | 동결 모델의 새 기간 그림자 평가 | 설계 | 없음 |

상태는 설계 → 등록 → 실행 → 검증 완료 → 채택/기각/보류로 기록합니다. 결과를 본 뒤 변경한 가설은 원래 등록을 수정해 숨기지 않고 새 ID로 이어갑니다. 현재의 설계 목록을 이미 사전 등록된 실험으로 표현하지 않습니다.

## 확장 연구 상태 R0–R7

E0–E5는 모델·입력 검증을 위한 기존 실험이고 R0–R7은 더 넓은 분석·운영 연구입니다. 중복되는 주제는 연결해 관리합니다.

| ID | 연구 | 상태 | 확인한 범위 |
| --- | --- | --- | --- |
| R0 | 평가용 데이터마트·품질 분석 | 완료 경기 범위 실행·대조 | SQLite 집계와 기존 결산 일치. 전체 일정 버전·실행 이력은 미구축 |
| R1 | 예측 시점별 정보 가치 | 시간 감사 실행, 정보 가치 비교 대기 | T−30 근거 반영·접수 여유 분석. 다중 시점 입력 수집 미실행 |
| R2 | 실패 조건·분포 변화 | 불일치 구간 회고 진단 | 동일 경기 구간·월별 비교, 날짜·7일·14일 불확실성. 경보 적용 미실행 |
| R3 | 제출 없는 포스트시즌 평가 | 설계 | 이용 조건·평가 시각 확정 전, 실제 예측 미실행 |
| R4 | 시리즈 진출·길이·민감도 | 합성 계산 구현·검증 | 실제 팀 확률 추정·KBO 경기 성능 검증 아님 |
| R5 | 단순 모델·확률 품질 비교 | E1–E4와 연결한 설계 | 새 학습·보정 미실행 |
| R6 | 자동화의 업무 효과 | 보존 시각 분석, 업무 효과 대기 | 생성→접수 일부 측정. 계산 전체 시간·수동 개입·전후 효과 미측정 |
| R7 | 별도 공개 자료의 재현 연구 | 후보 자료 검토 | 자료 다운로드·새 학습 미실행 |

원천과 허용 범위:
입력 정의 버전 / 가용 시각 검증 / 결측 정책:

## 실행 후 작성

```text
실행일 / 실행 명령 / 환경과 라이브러리 버전:
완료 날짜 / 실패 날짜 / 재시도:
총 경기 / 평가 경기 / 제외 사유 / 누락 사유:
생성 시각·확률 재현 검사 / 대회 제출 모드의 마감 전 접수 검사:
같은 경기의 두 모델 적중 수 / 승자 변경의 개선·악화 수:
Brier / LogLoss / AUC:
확률 구간별 표본 수 / 보정 곡선 / 50.00% 발생:
모델 차이와 날짜·블록별 불확실성:
비교한 전체 후보 수 / 선택에 사용한 구간:
가설 유지·기각·보류의 근거:
예상과 다른 결과 / 입력 오류 / 실패한 후보:
채택 여부 / 새 독립 평가가 필요한 이유:
공개 가능한 요약 / 비공개 원본 산출물 보존 위치:
```

학습·보정·평가가 끝난 산출물의 해시를 보존하되 인증 정보나 비공개 운영 경로를 공개 문서에 적지 않습니다. 내부 회고 점수를 공식 참가 성적으로 쓰거나 미실행 후보의 예상 점수를 채우지 않습니다.
