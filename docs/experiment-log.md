# 실험 기록 양식

후속 연구의 가설·자료 시점·선택 과정·평가 결과를 하나의 기록으로 연결합니다. 아래 후보는 아직 설계 단계이며 실행 전 등록해야 할 조건을 구체화하기 위한 목록입니다.

[문서 목록](README.md) · [연구 고도화 계획](research-plan.md)

## 현재 후보 상태

| ID | 제목 | 상태 | 관측된 새 성능 |
| --- | --- | --- | --- |
| E0 | 입력 정의·가용 시각의 정합성 | 설계 | 없음 |
| E1 | 원시 투수 카운트와 표본 수축 | 설계 | 없음 |
| E2 | 리그 환경 상대 지표와 단순 모델 | 설계 | 없음 |
| E3 | 독립 구간의 낮은 자유도 보정 | 설계 | 없음 |
| E4 | 날짜·블록 단위 불확실성 | 설계 | 없음 |
| E5 | 동결 모델의 새 기간 그림자 평가 | 설계 | 없음 |

상태는 설계 → 등록 → 실행 → 검증 완료 → 채택/기각/보류로 기록합니다. 결과를 본 뒤 변경한 가설은 원래 등록을 수정해 숨기지 않고 새 ID로 이어갑니다. 현재의 설계 목록을 이미 사전 등록된 실험으로 표현하지 않습니다.

## 실행 전 작성

```text
실험 ID / 작성일 / 작성자:
상태:
질문과 반증 가능한 가설:
변경하는 요소 / 그대로 두는 비교 조건:
원천과 허용 범위:
입력 정의 버전 / 가용 시각 검증 / 결측 정책:
학습 기간:
내부 날짜순 후보 선택 기간:
보정 기간:
최종 평가 기간 / 시작·종료 조건:
이미 결과를 확인한 기간:
기준 모델과 확률 기준:
튜닝 공간 / 허용 시도 수 / 모든 시도 기록 위치:
적중·확률·운영 품질의 채택 기준과 허용 악화 폭:
날짜·블록 재표집 조건:
모델·입력·설정 해시의 보존 위치:
```

## 실행 후 작성

```text
실행일 / 실행 명령 / 환경과 라이브러리 버전:
완료 날짜 / 실패 날짜 / 재시도:
총 경기 / 평가 경기 / 제외 사유 / 누락 사유:
생성 시각·마감 전 접수·확률 재현 검사:
같은 경기의 두 모델 적중 수 / 승자 변경의 개선·악화 수:
Brier / LogLoss / AUC:
확률 구간별 표본 수 / 보정 곡선 / 50.00% 발생:
모델 차이와 날짜·블록별 불확실성:
비교한 전체 후보 수 / 선택에 사용한 구간:
가설 유지·기각·보류의 근거:
예상과 다른 결과 / 입력 오류 / 실패한 후보:
채택 여부 / 새 독립 평가가 필요한 이유:
공개 가능한 요약 / 비공개 원본 산출물 보존 위치:
```

학습·보정·평가가 끝난 산출물의 해시를 보존하되 인증 정보나 비공개 운영 경로를 공개 문서에 적지 않습니다. 내부 회고 점수를 공식 참가 성적으로 쓰거나 미실행 후보의 예상 점수를 채우지 않습니다.
